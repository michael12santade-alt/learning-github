# 🌐 Dummy Static Website

This is a simple static website built using **HTML** and **CSS**.  
It is designed as a beginner-friendly project to understand the basic structure of a web page and how external CSS works.

---

## 📂 Project Structure
project-folder/
│
├── index.html
├── style.css
└── README.md


---

## 🚀 Features

- Semantic HTML structure
- External CSS styling
- Responsive layout
- Navigation bar
- Card-based content sections
- Sample image integration
- Clean and simple UI

---

## 🛠 Technologies Used

- HTML5
- CSS3

---

## 📖 How to Run the Project

1. Download or clone the repository.
2. Make sure `index.html` and `style.css` are in the same folder.
3. Open `index.html` in your browser.

That's it! 🎉

---

## 🎯 Purpose of This Project

This project is created for:
- Learning basic web development
- Understanding how HTML links to external CSS
- Practicing layout and styling concepts
